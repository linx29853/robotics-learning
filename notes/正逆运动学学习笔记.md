## 2. 二连杆机械臂模型

机械臂由两个旋转关节组成：

- $q_1$：第一关节相对基坐标系的角度；
- $q_2$：第二关节相对第一连杆的角度；
- $a_1$：第一连杆长度；
- $a_2$：第二连杆长度；
- $(x,y)$：末端执行器在基坐标系中的位置。

需要特别注意：第二连杆相对基坐标系的绝对角度不是 $q_2$，而是：

$$
q_1+q_2
$$

因此两个关节角共同决定末端位置。

## 3. 正运动学

### 3.1 正运动学解决什么问题

已知关节角和连杆长度：

$$
(q_1,q_2,a_1,a_2)
$$

计算末端位置：

$$
(x,y)
$$

即：

$$
(q_1,q_2) \longrightarrow (x,y)
$$

### 3.2 几何解析公式

第一连杆末端位置为：

$$
x_1=a_1\cos q_1
$$

$$
y_1=a_1\sin q_1
$$

第二连杆贡献的位移为：

$$
x_2=a_2\cos(q_1+q_2)
$$

$$
y_2=a_2\sin(q_1+q_2)
$$

因此末端位置为：

$$
x=a_1\cos q_1+a_2\cos(q_1+q_2)
$$

$$
y=a_1\sin q_1+a_2\sin(q_1+q_2)
$$

对应代码：

```python
import numpy as np


def forward_kinematics_closed_form(q1, q2, a1, a2):
    x = a1 * np.cos(q1) + a2 * np.cos(q1 + q2)
    y = a1 * np.sin(q1) + a2 * np.sin(q1 + q2)
    return np.array([x, y])
```

### 3.3 标准 DH 变换矩阵

本实验使用的单节标准 DH 变换矩阵为：

$$
{}^{i-1}T_i=
\begin{bmatrix}
\cos\theta_i & -\sin\theta_i\cos\alpha_i & \sin\theta_i\sin\alpha_i & a_i\cos\theta_i \\
\sin\theta_i & \cos\theta_i\cos\alpha_i & -\cos\theta_i\sin\alpha_i & a_i\sin\theta_i \\
0 & \sin\alpha_i & \cos\alpha_i & d_i \\
0 & 0 & 0 & 1
\end{bmatrix}
$$

对于平面二连杆机械臂：

$$
d_1=d_2=0,\qquad \alpha_1=\alpha_2=0
$$

且：

$$
\theta_1=q_1,\qquad \theta_2=q_2
$$

两节连杆的总变换为：

$$
{}^0T_2={}^0T_1{}^1T_2=A_1A_2
$$

代码实现：

```python
def dh_transform(theta, d, a, alpha):
    ct = np.cos(theta)
    st = np.sin(theta)
    ca = np.cos(alpha)
    sa = np.sin(alpha)

    return np.array([
        [ct, -st * ca,  st * sa, a * ct],
        [st,  ct * ca, -ct * sa, a * st],
        [0.0,       sa,       ca,      d],
        [0.0,      0.0,      0.0,    1.0],
    ], dtype=float)


def forward_kinematics_dh(q1, q2, a1, a2):
    A1 = dh_transform(q1, 0.0, a1, 0.0)
    A2 = dh_transform(q2, 0.0, a2, 0.0)
    return A1 @ A2
```

末端位置位于齐次变换矩阵的最后一列：

```python
T02 = forward_kinematics_dh(q1, q2, a1, a2)
position = T02[:2, 3]
```

### 3.4 `@` 与 `*` 的区别

NumPy 中：

- `A @ B`：矩阵乘法；
- `A * B`：对应元素相乘。

串联机械臂的坐标变换必须使用矩阵乘法：

```python
T02 = A1 @ A2
```

原仓库 DH 路径中曾出现使用 `*` 累乘齐次变换矩阵的问题。这会破坏坐标变换的组合关系，得到错误的末端位置。原仓库的快速解析正运动学路径是正确的，因此默认动画仍可能正常运行，从而隐藏这个问题。

另外，原仓库控制台虽然输出“modified DH”，但其单节矩阵形式实际对应标准 DH。判断 DH 类型应以矩阵定义和建系规则为准，不能只看输出文字。

### 3.5 正运动学验证结果

取：

$$
q_1=30^\circ,\qquad q_2=45^\circ
$$

$$
a_1=0.30,\qquad a_2=0.25
$$

计算得到：

$$
(x,y)\approx(0.32451238,\ 0.39148146)
$$

DH 矩阵法与几何解析公式的误差约为：

$$
7.85\times10^{-17}
$$

该误差来自浮点数计算，可以视为数值上一致。

随机验证方法：

```python
def verify_random_configurations():
    rng = np.random.default_rng(seed=42)
    a1, a2 = 0.30, 0.25

    for _ in range(100):
        q1, q2 = rng.uniform(-np.pi, np.pi, size=2)

        position_dh = forward_kinematics_dh(
            q1, q2, a1, a2
        )[:2, 3]

        position_closed_form = forward_kinematics_closed_form(
            q1, q2, a1, a2
        )

        assert np.allclose(
            position_dh,
            position_closed_form,
            atol=1e-12,
        )
```

验证的意义是：一个样例只能说明代码在一个点上正确，随机测试可以检查不同象限和不同关节姿态。

## 4. 逆运动学

### 4.1 逆运动学解决什么问题

已知目标位置和连杆长度：

$$
(x,y,a_1,a_2)
$$

求关节角：

$$
(q_1,q_2)
$$

即：

$$
(x,y) \longrightarrow (q_1,q_2)
$$

逆运动学通常比正运动学复杂，因为它可能：

- 无解：目标点超出工作空间；
- 有多个解：不同关节姿态到达同一点；
- 在边界处出现重合解；
- 在奇异位置附近对误差敏感。

### 4.2 工作空间与可达性

令目标点到基座的距离为：

$$
r=\sqrt{x^2+y^2}
$$

二连杆机械臂可达的条件为：

$$
|a_1-a_2|\le r\le a_1+a_2
$$

本实验中：

$$
0.05\le r\le0.55
$$

因此：

- $(0.55,0)$ 位于外边界，可达；
- $(0.05,0)$ 位于内边界，可达；
- $(0.60,0)$ 太远，不可达；
- $(0,0)$ 太近，不可达。

### 4.3 求解第二关节角 $q_2$

由余弦定理：

$$
x^2+y^2=a_1^2+a_2^2+2a_1a_2\cos q_2
$$

因此：

$$
c_2=\cos q_2=
\frac{x^2+y^2-a_1^2-a_2^2}{2a_1a_2}
$$

若 $c_2\notin[-1,1]$，目标点不可达。

由于：

$$
\sin q_2=\pm\sqrt{1-c_2^2}
$$

所以一般会产生两组解：

$$
q_2=\operatorname{atan2}(+\sqrt{1-c_2^2},c_2)
$$

$$
q_2=\operatorname{atan2}(-\sqrt{1-c_2^2},c_2)
$$

使用 `atan2(sin, cos)`，能够保留角度所在象限的信息。

```python
def solve_q2(x, y, a1, a2):
    r_squared = x**2 + y**2
    c2 = (
        r_squared - a1**2 - a2**2
    ) / (2.0 * a1 * a2)

    tolerance = 1e-12
    if c2 < -1.0 - tolerance or c2 > 1.0 + tolerance:
        raise ValueError("目标点不可达")

    # 消除边界处的浮点误差，例如 1.0000000000000002。
    c2 = np.clip(c2, -1.0, 1.0)
    s2_abs = np.sqrt(max(0.0, 1.0 - c2**2))

    q2_positive = np.arctan2(s2_abs, c2)
    q2_negative = np.arctan2(-s2_abs, c2)

    return q2_positive, q2_negative
```

检查可达性和裁剪必须发生在开平方之前，否则边界浮点误差可能造成：

```text
RuntimeWarning: invalid value encountered in sqrt
```

并产生 `NaN`。

### 4.4 求解第一关节角 $q_1$

目标点相对基座的方向角为：

$$
\phi=\operatorname{atan2}(y,x)
$$

第二连杆造成的几何修正角为：

$$
\beta=\operatorname{atan2}
\left(
a_2\sin q_2,
a_1+a_2\cos q_2
\right)
$$

因此：

$$
q_1=\phi-\beta
$$

代码实现：

```python
def solve_q1(x, y, a1, a2, q2):
    target_angle = np.arctan2(y, x)
    correction_angle = np.arctan2(
        a2 * np.sin(q2),
        a1 + a2 * np.cos(q2),
    )
    return target_angle - correction_angle
```

每一个 $q_2$ 都必须配对计算对应的 $q_1$，不能把不同分支的角度混合。

### 4.5 完整解析逆运动学

```python
def inverse_kinematics(x, y, a1, a2):
    q2_positive, q2_negative = solve_q2(x, y, a1, a2)

    q1_positive = solve_q1(x, y, a1, a2, q2_positive)
    q1_negative = solve_q1(x, y, a1, a2, q2_negative)

    return [
        (q1_positive, q2_positive),
        (q1_negative, q2_negative),
    ]
```

对于正运动学样例的目标位置：

$$
(x,y)=(0.32451238,\ 0.39148146)
$$

逆运动学得到两组解：

$$
(q_1,q_2)\approx(30^\circ,45^\circ)
$$

$$
(q_1,q_2)\approx(70.687^\circ,-45^\circ)
$$

这两组姿态通常称为“肘上”和“肘下”解。它们的关节角不同，但末端位置相同。

## 5. 用正运动学验证逆运动学

逆运动学不能只看求出的角度是否“像是正确的”。最可靠的基础验证是把每组逆解代回正运动学：

$$
(q_1,q_2)\xrightarrow{FK}(x',y')
$$

再计算位置误差：

$$
e=\sqrt{(x'-x)^2+(y'-y)^2}
$$

```python
def verify_solution(target, solution, a1, a2):
    q1, q2 = solution
    reconstructed = forward_kinematics_closed_form(
        q1, q2, a1, a2
    )

    error = np.linalg.norm(reconstructed - target)
    assert error < 1e-9
    return reconstructed, error
```

本实验的验证结果为：

- 普通目标点的两组解均成功回代；
- 回代误差约为 $10^{-16}$；
- 外边界点对应完全伸直状态；
- 内边界点对应反向折叠状态；
- 超出工作空间的点被明确拒绝；
- 修正计算顺序后不再出现 `NaN`。

## 6. 多解、边界与奇异性

### 6.1 为什么会有两组逆解

同一个目标点通常可以由两种弯曲方向到达：

- $\sin q_2>0$；
- $\sin q_2<0$。

因此位置任务通常不能唯一决定机械臂姿态。真实控制系统还要根据以下条件选择解：

- 与当前关节角的距离；
- 关节限位；
- 是否碰撞；
- 轨迹是否连续；
- 能耗或运动时间。

### 6.2 为什么边界处两解会重合

外边界：

$$
q_2=0
$$

机械臂完全伸直。

内边界：

$$
q_2=\pm\pi
$$

两根连杆反向折叠。

这时：

$$
\sin q_2=0
$$

正负分支代表相同或等价的几何姿态，因此两组解会重合。

### 6.3 奇异性的初步理解

在完全伸直或完全折叠时，机械臂处于奇异位置。此时某些方向上的末端速度无法由有限、稳定的关节速度产生。

这为下一阶段学习雅可比矩阵提供了入口：

$$
\dot{p}=J(q)\dot{q}
$$

当雅可比矩阵失去满秩时，机械臂处于奇异状态。

## 7. 本次复现中形成的调试方法

### 7.1 不把“代码能运行”当作复现完成

一次有效复现至少应当包含：

1. 能解释输入和输出；
2. 能独立写出核心公式；
3. 能使用另一种方法交叉验证；
4. 能覆盖普通点、边界点和异常点；
5. 能解释误差来源；
6. 能定位与修复实现问题。

### 7.2 用独立实现交叉验证

本实验使用了三层验证：

1. DH 矩阵法计算正运动学；
2. 几何解析公式验证 DH 结果；
3. 正运动学回代验证逆运动学。

其关系为：

```text
关节角 ──DH 正运动学──> 末端位置
   │                         │
   └──解析正运动学───────────┘

末端目标 ──逆运动学──> 两组关节角
                         │
                         └──正运动学回代──> 原目标
```

### 7.3 数值计算必须考虑容差

理论上的 $\cos q_2=1$，在计算机里可能变成：

```text
1.0000000000000002
```

因此数值程序通常需要：

- 容差判断；
- `np.clip`；
- 使用 `np.allclose`，而不是直接用 `==`；
- 对平方根、除法等敏感运算检查定义域。

### 7.4 测试代码也可能产生假象

测试中的 `assert` 必须放在真正要验证的循环内部。异常分支应使用 `continue` 或明确返回，避免继续使用上一轮残留的变量。

推荐结构：

```python
try:
    solutions = inverse_kinematics(...)
except ValueError as error:
    print(error)
    continue

for solution in solutions:
    reconstructed = forward_kinematics_closed_form(...)
    error = np.linalg.norm(reconstructed - target)
    assert error < 1e-9
```

雅可比矩阵为：

$$
J(q)=
\begin{bmatrix}
-a_1\sin q_1-a_2\sin(q_1+q_2) & -a_2\sin(q_1+q_2) \\
a_1\cos q_1+a_2\cos(q_1+q_2) & a_2\cos(q_1+q_2)
\end{bmatrix}
$$

它将成为后续速度控制、数值逆运动学、奇异性分析和轨迹跟踪的共同基础。

## 10. 核心结论

> 正运动学回答“给定关节角，末端在哪里”；逆运动学回答“希望末端到这里，关节应该怎么转”。

> DH 方法的核心不是背矩阵，而是通过坐标变换逐节建立机械臂的空间关系。

> 逆运动学求出角度并不代表验证完成，必须使用正运动学回代。

> 机器人算法既要理解几何和公式，也要处理多解、工作空间、奇异性与浮点误差。
